# 22. VICTORY CONDITIONS

## \* 22.1 INDIVIDUAL VICTORY - EC game #3 ONLY

When a single Ruler controls 100 or more worlds for four consecutive turns, and no other single Ruler has control of more than half as many, then that Ruler wins the game and the game is over.

## \* 22.2 RACIAL VICTORY - EC game #3 ONLY

If any one race as a group controls 250 or more worlds for four consecutive turns, or if all of the existing colonies (not ships) belong to one race, the game is over and a racial victory is declared.

## \* 22.3 INDIVIDUAL VICTORY - ALL OTHER EC games

\* When a single Ruler gains control of 15 or more of the total habitability, (the sum of all of the habitability numbers of all the planets in the game), for 4 consecutive turns and no other single Ruler has half as much, the game is over and that Ruler wins.

## \* 22.4 RACIAL VICTORY - ALL OTHER EC games

\* When a race, as a group, controls 50% or more of the total habitability in the game for four consecutive turns while no other race controls half as much, then a racial victory is declared.

\* Indicates line has been revised, deleted or added on.
