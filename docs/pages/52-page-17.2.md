## 17.4 ORDER FORMATS AND EXAMPLES

### 17.4.1 TACTICAL MANEUVER ORDERS (TMV)

- Format: Ship ID#, "TMV", new tactical coordinates.
- Example: 250, TMV, 1,-5,2.
- Notes: The TMV order causes ship #250 to fly to position 1,-5,2 around the planet or as close to that position as the ship's speed allows.

### 17.4.2 CLOSE ORDERS (CLS)

- Format: Ship ID#, "CLS", target ship.
- Example: 250, CLS, 261.
- Notes: The CLS order moves ship 250 as close to 261 as 250's speed allows.

### 17.4.3 RUN ORDERS (RUN)

- Format: Ship ID#, "RUN", target ship.
- Example: 250, RUN, 261.
- Notes: The RUN order moves ship 250 as far away from ship 261 as 250's speed allows.

### 17.4.4 PRE-MANEUVER ENERGY WEAPON FIRE ORDERS (PME)

- Format: S/C ID#, "PME", target s/c, % of EWP firing, target.
- Example: 190, PME, 210, 10, 4.
- Notes: The PME order has s/c #190 fire 10% of its EWP at colony 210's mine groups before any ship maneuver orders are processed.
