### 17.4.11 OFFENSIVE TROOP SUPPORT ORDERS (OTS)

- Format:
  ```text
  S/C ID#, "OTS", target s/c, s/c to be supported
  Quantity, item.
  1, END.
  ```
- Example:
  ```text
  25, OTS, 30, 29.
  10,000, MRB-1
  10,000, ASC-2.
  10,000, ASW-1.
  1, END.
  ```
- Notes: The OTS order has s/c 25 assign 10,000 MRB-1, 10,000 ASC-2, and 10,000 ASW-1 to the support of colony 29 in its attack on s/c 30.

### 17.4.12 WITHDRAW ORDERS (WTD)

- Format:
  ```text
  S/C ID#, "WTD", target s/c.
  Quantity, item.
  1, END.
  ```
- Example:
  ```text
  27, WTD, 17.
  15,000, SLD-1.
  10, ASC-1.
  1, END.
  ```
- Notes: The WTD order has s/c 27 withdraw from s/c 17.
  WTD is an all-or-nothing order.

### 17.4.13 PERMISSION TO COLONIZE ORDERS (PTC)

- Format: Colony ID#, "PTC", ship ID requesting permission.
- Example: 308, PTC, 479.
- Notes: The PTC order, written by 308, the controller of the planet, gives permission to ship 479 to set up a colony there.

### 17.4.14 ALLOW ADD-ON ORDERS (AAN)

- Format: S/C ID#, "AAN", s/c to do the add-on.
- Example: 205, AAN, 38.
- Notes: The AAN order allows s/c 38 to add-on items to s/c 205.

#### 17.4.14.1 Multiple Target AAN Orders

- Format: S/C ID#, "AAN", s/c's to do the add-ons.
- Example: 205, AAN, 38, 39, 42, 46, 48, 49.
- Notes: The multiple target AAN order allows s/c's 38, 39, 42, 46, 48, and 49 to add-on items to s/c 205.

### 17.4.15 SET UP ORDERS (STP)

- Format:
  ```text
  S/C ID#, "STP", type of s/c to be set up.
  Quantity, item.
  Quantity to be set up, "END".
  ```
- Example:
  ```text
  29, STP, SHP.
  50,000, STUN.
  5, PRO-2.
  1, SDRV-1.
  20, FOOD.
  5, LFS-1.
  1, SEN-1.
  1000, FUEL.
  100,HDRV-1.
  20, CNGD.
  6, END.
  ```
- Notes: The STP order has colony 29 set up 6 identical ships.
  (There is never more than one colony of any type set up on any turn).
  The items were listed in the order of their importance, with the STUN heading the list.
  Only one quantity and one type of unit is allowed per line.
  Note that the 5,000 FCT-1 will go into storage, but the 6,000 FCT-1 will be assembled and begin to make TPT-1.
  In order to STP a s/c for another player, the receiving player's ID# is entered after "the type of s/c to be set up" on the first line of the order.
  A s/c can be set up for a member of the same race only.
