10. MAXI-CHALLENGE HEAD START:
    Head start games are versions of MAXI-CHALLENGE.
    All the MAXI-CHALLENGE rules apply except for:
    - A. Each player starts with TL-5.
    - B. All starting materials are TL-5 items except for FRMs (-1).
    - C. Tech levels cost ten times as much in research as they do in other MC games.
      That is, TL-6 will cost 16 million research points, and TL-7 will cost 32 million.
    - D. Points are counted as in MC, but they are not cumulative.
    - E. The winner is the first player to create a 2500 point empire.
      If two or more achieve this on the same turn, then the highest point count wins.
      Also, if the number of rulers drops below 5, the game ends and the highest point count wins.
11. MAXI-CHALLENGE BITTER END:
    Bitterend uses the same rules as MAXI-CHALLENGE with the following exceptions:
    - A. The cost of tech-levels is 10 times a normal MC game, (same as in Head Start).
    - B. All 40 deposits at the home planet will be full at the start of the game.
    - C. The winner is the first ruler to control 50% or more of the total habitability in the game for four consecutive turns, during which no other player can control half as much habitability.
