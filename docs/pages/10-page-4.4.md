| Code | Definition |
| --- | --- |
| SLD | Soldier unit: Consists of 100 soldiers. |
| SLSU | Super-light structural units: Same as LTSU, only much lighter. |
| SPD | Space Drives: Maneuver in combat and keep ships in orbit. |
| SPM | Spy move: This order changes spies from one group or target to another. |
| SPYS | Spy unit: Consists of one PRO and one SLD, therefore 200 people. |
| STP | Set-up: This order establishes a ship or colony. |
| STU | Start-up: This order starts up all farms in a s/c, when shut down. |
| STUN | Structural units: Same as LTSU, but these are the heaviest. |
| SUR | Survey: This order searches a planet for research deposits. |
| SYS | System: Solar system |
| \* SOL\* | Standard of living: Total CNGD paid ÷ by total POP, then ÷ by 4. |

## T

| Code | Definition |
| --- | --- |
| TFR | Transfer: This order transfers units from one s/c to another. |
| TL | Technological level: S/c's level of scientific advancement. |
| TMV | Tactical maneuver: This order places a ship at a specific point by a planet. |
| TN\* | Turn: Game turn. |
| TPT | Transport: Unarmed vehicle used to make transfers and in combat. |
| TRN | Trainee unit: Consists of 100 people who will graduate to be PRO's. |

## U

| Code | Definition |
| --- | --- |
| UEM | Unemployable unit: Consists of 100 of the elderly, disabled, etc. |
| UNA\* | Unassembled items: Assembly type items that have been DAS'd. |
| UNC | Uncontrol: This order releases control of a planet. |
| USK | Unskilled unit: Consists of 100 manual laborers. |

## W

| Code | Definition |
| --- | --- |
| WIP\* | Work in process: Items in the process of being manufactured. |
| WTD | Withdraw: This order withdraws troops from combat. |

In writing orders all words listed in the Glossary should be abbreviated in the same manner in the orders.
Abbreviations followed by astericks are never used in writing orders, but are used in the text of this rule book, or in the printouts you receive.

\* Indicates line has been revised or added on.
