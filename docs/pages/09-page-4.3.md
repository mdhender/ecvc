| Code | Definition |
| --- | --- |
| NMTS | Non-metallics: All non-metallic resources. |
| NOM | Name of player: This order names a player. |
| NON\* | Non-assembly items: Applies to items that can't be assembled. |
| NSR | News release: This order puts a message into the News Service. |

## O

| Code | Definition |
| --- | --- |
| OBC | Orbiting colony: Colony that orbits a planet. |
| OPC | Open colony: Surface colony open to enviornment. |
| OTS | Offensive troop support: See Combat (15.0) |

## P

| Code | Definition |
| --- | --- |
| PAY | Pay: This order changes standing wages. |
|  | Player: A Ruler or a Regent. |
| PME | Pre-maneuver energy weapon fire: See Combat (15.0). |
| PMM | Pre-maneuver missile fire: See Combat (15.0). |
| POP\* | Population unit: consists of 100 people, except SPYS and CNW's. |
| PRB | Probe: This order gathers data about a system and nearer stars. |
| PRO | Professional unit: consists of 100 highly skilled people. |
| PTC | Permission to colonize: This order permits a s/c set up on a planet controlled by another player. |
| PUP | Pick-up: This order has transports pickup items from another s/c. |

## Q

| Code | Definition |
| --- | --- |
| QTY\* | Quantity: number, amount. |

## R

| Code | Definition |
| --- | --- |
| RAD | Raid: See Combat (15.0) |
| \* RBS\* | Rebel soldiers: Percentage of soldier population willing to rebel. |
| \* REB\* | Rebels: Percentage of people other than soldiers willing to rebel. |
| REC | Receive: This order receives items transferred from another s/c. |
|  | Regent: A player who manages a Ruler's s/c's, follows his orders. |
| RETL | Retool: This order changes the item being built by a FCT group. |
| RSCH | Research point: A unit of research, built by a factory. |
| RTN | Ration: This order sets the amount of food eaten in the s/c's. |
|  | Ruler: Player, not a Regent, who controls a s/c. |
| RUN | Run: This order has one ship run from another ship. |

## S

| Code | Definition |
| --- | --- |
| S/C | Ship or colony: Any ship or colony, interchangeably. |
| SCR | Scrap: This order converts items back into METS and NMTS. |
| SEL | Sell: This order sells items to or through the market. |
| SEN | Sensors: Devices to do probes and improve EWP and MSL firing. |
| SHP | Ship: Spaceship. |
| SHT | Shut-down: This order shuts down all farms in a s/c. |
