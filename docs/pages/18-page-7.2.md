## 7.4 SET UPS

### 7.4.1 DESCRIPTION

A set up (STP) order establishes a new s/c.
A s/c does not have to be established all in one turn; part may be set up on one turn, and the rest of it can be built on following turns, using add-on orders and transfer orders.
The computer places newly set up ships between 2 and 3 distance units from the planet.

### 7.4.2 S/C ID NUMBERS

The player does not assign an ID number to a s/c.
When the computer receives a set up order, it assigns the ID number for the s/c automatically; the player sees it on the next printout.

### 7.4.3 SET UP RESTRICTIONS

S/c's may establish any other type or number of ships and colonies, providing restrictions listed below are met.

#### 7.4.3.1 Restrictions on Type of S/C

A player may not set up a colony if this would result in more than one of each type of colony at the same location.
This does not apply to ships; only 99 ships may be set up at the same location by the same player.

#### 7.4.3.2 Restrictions Ruler - Regent

A Ruler may not set up a colony of one kind if his Regent already owns a colony of that kind at that location.
Conversely, a Regent may not set up the same kind of colony that his Ruler has in the same location, or that another of his Ruler's regents has in that location.

#### 7.4.3.3 Permission to Colonize

A player may not set up a colony on a planet controlled by another player, unless he has communicated with the other player asking his permission to colonize, and the controller has agreed and has written a permission to colonize order (PTC).
There is no limit to the number of players that may establish colonies at a location, as long as PTC is granted, and as long as the limit of one of each type of colony per location per player is observed.
When a player has received PTC on a planet, he does not need it to set up more colonies there.

#### 7.4.3.4 Failures to Set Up

All set-up orders, whether for ships or colonies, will abort if no population are included in the set up order.
A ship set up will also abort if no SDRV are included.
Portions of a STP, or all of it, may fail due to a shortage of construction workers, transports, fuel (for the transports), or due to a shortage of STUN, LTSU, or SLSU (there must be enough to hold the units being STP).
The s/c's otherwise have no size limitations, and players may build them as they choose.
